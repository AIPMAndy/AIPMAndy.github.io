- 所有案例和 CSV 都是**虚构的教学模拟数据**。
- 不要在 GitHub Issue、反馈表或公开提示词中提交个人隐私、公司密钥、Token、内部合同或客户资料。
- AI 对外发消息、删除/覆盖文件、提交合同、转账、变更权限前必须人工确认。
- 技能文件是**平台中立的示范规范**，不是豆包官方认证插件；使用前需审查与适配。
- 建议只在隔离的练习目录中初次体验 GUI、本地文件与自动化功能。

发现漏洞请优先以私密渠道联系仓库维护者；不要公开发布可直接利用的用户秘密。
