# Agent 任务委托协议

> 模板可在豆包工作、WorkBuddy、Codex 等 Agent 中迁移；所需连接器与权限需重新适配。

1. **目标**：需要完成的业务结果是什么？
2. **交付对象**：谁决定做得好不好？
3. **输入材料**：列出允许使用的文件/网址/知识源。
4. **范围时效**：地区、时间范围、截止时间和排除项。
5. **执行限制**：白名单、不得覆盖、禁止外发、禁止获取密钥。
6. **输出格式**：Markdown、CSV、PPTX、HTML 等可编辑成果。
7. **验收标准**：至少 3 个可以客观验证的条件。
8. **人工确认**：外发、发布、付款、删除、生产写入与授权变更的审批人。
