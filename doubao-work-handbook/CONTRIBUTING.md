# 贡献指南

欢迎在 GitHub Issues 里反馈教程事实错误、失效入口、错误链接、移动端排版问题和可复现案例。请脱敏后提交系统、版本、入口（豆包账号 / 飞书账号）、预期行为、实际行为、复现步骤和权威来源。

本项目坚持：**不编造客户、收入、Offer、使用效果、额度和产品能力**；定价/功能以最新官方页面和实际账户为准；所有演示数据必须显著标记“教学模拟”；提交第三方代码/Skill 时标注来源及授权；新增 UI 功能需要有客观质量检查。

内容编辑：修改 `content/chapters.json` / `content/prompts.json` / `content/sources.json`，然后运行 `python scripts/build.py`。网站和 PDF 来自同一个知识源。
