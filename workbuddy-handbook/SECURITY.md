# 安全与隐私

- 本仓库的公开示例均为虚构教学数据，不使用任何真实客户个人信息。
- 网站静态运行，默认无分析脚本、注册、Cookie 追踪或第三方请求；外链仅在用户点击时打开。
- 任务提示词默认明确“不得上传敏感资料、不得覆盖原文件、不得未经许可对外发送”。
- 使用第三方 Skill、MCP、CLI 或连接器前，必须审查权限、网络请求、可执行脚本、密钥使用范围。
- 请勿在 GitHub issue 或 PR 提交真实访问令牌、密码、个人身份信息、患者信息、私人邮件或客户合同。
- 安全问题请通过作者网站上公开的渠道联系；不要在公开 Issue 张贴可利用的敏感内容。
- MIT License 仅涵盖本仓库原创内容，不授予第三方软件或商标权益。
