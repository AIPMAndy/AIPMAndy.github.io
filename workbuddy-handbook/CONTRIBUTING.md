# 贡献指南

欢迎修复事实、更新官方 UI 变化、补充匿名可复现工作流。

1. 优先修改 `content/guide.md`（教程）或 `content/prompts.json`（模板）；不要直接只改生成的 `docs/index.html` 或 PDF。
2. 提交前运行 `python scripts/build_all.py && python scripts/check_site.py`，如未运行，请在 PR 说明。
3. 所有功能性断言必须提供官方文档 URL、产品版本、适用地区和核验日期。
4. 案例按等级标记：真实且可核验且获授权、第三方可追溯、教学模拟。不能把模拟结果当成交、收入、Offer 或模型实测。
5. 不接受含密钥、敏感个人信息、客户合同、未经授权的第三方素材的提交。
6. 对 UX 提供桌面/手机截图（请打码）与可复现步骤；对 PDF 缺陷提供页码和阅读器。
7. 维护独立、客观、中立表述：项目非腾讯官方产品或代言。
