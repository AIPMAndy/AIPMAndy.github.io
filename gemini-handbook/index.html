05 / QUALITY & SAFETY

先保证可验证，再讨论效率。

AI 助手可以生成内容，但最终事实、权限和对外交付责任不能外包给模型。

01 / SOURCE

来源可追溯

数据有口径；研究有原链接；图片内容有原图。事实、假设和建议分开。

02 / PERMISSION

最小权限

不上传不必要的客户数据。CLI 用独立项目目录，写入、删除、外发都需审核。

03 / SECURITY

密钥不进前端

API Key 放环境变量或服务端。限制访问、预算与速率，不把密钥提交 GitHub。

04 / VERIFICATION

明确验收状态

通过、失败、未验证分别记录。不把模型自称执行成功当作外部事实。
